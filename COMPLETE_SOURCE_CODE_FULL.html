45 @staticmethod

48 Calculate Merkle root from list of transaction hashes

93 Used in block headers

163 Create Bitcoin address from public key
164 Uses double SHA-256 for checksum
165 """
166 # Hash public key
167 pubkey_hash = BitcoinCrypto.hash160(pubkey)
