## 🚀 Quick Start

### Prerequisites

1. **Bitcoin Core** must be installed on your system
   - Download from: https://bitcoin.org/en/download
   - Install to default location or update path in settings

2. **Node.js** >= 18.0.0
   - Download from: https://nodejs.org/

3. **System Requirements**
   - **Storage**: Minimum 500GB free space (for full blockchain)
   - **RAM**: 4GB minimum, 8GB recommended
   - **Network**: Broadband internet for initial sync

### Installation

```bash
cd packages/bitcoin-desktop

# Install dependencies
npm install

# Development mode
npm run dev

# Build for production
npm run build

# Package for distribution
npm run package
```

### First Run

1. **Launch Application**
   ```bash
   npm start
   ```

2. **Wait for Bitcoin Core to Start**
   - The application will automatically start bitcoind
   - Initial sync may take several days to download full blockchain

3. **Create Wallet**
   - Navigate to "Wallet" page
   - Click "New Address" to create your first wallet
   - **IMPORTANT**: Backup your mnemonic phrase immediately

4. **Monitor Sync Progress**
   - Check dashboard for sync status
   - Node must be fully synced before transacting

## 🔧 Configuration

### Bitcoin Core Settings

The application automatically creates `bitcoin.conf` with:

```conf
# Network
server=1
rpcuser=bitcoinrpc
rpcpassword=<auto-generated>
rpcport=8332
maxconnections=125

# Blockchain
txindex=1
prune=0  # Full node (not pruned)

# Performance
dbcache=4096
par=4
```

### Data Directory

Default locations:
- **Windows**: `C:\Users\<user>\.bitcoin-desktop-jmr`
- **macOS**: `/Users/<user>/.bitcoin-desktop-jmr`
- **Linux**: `/home/<user>/.bitcoin-desktop-jmr`

### Custom Configuration

Modify settings via Settings page or directly edit stored config.

## 🛡️ Security Best Practices

### 1. Backup Your Wallet

```bash
# Via UI: Wallet > Backup Wallet
# Or manually backup:
cp ~/.bitcoin-desktop-jmr/wallets/wallet.dat ~/secure-backup/
```

### 2. Secure Your Mnemonic

- Write down your 12-word mnemonic phrase
- Store in multiple secure physical locations
- **NEVER** store digitally or take photos
- **NEVER** share with anyone

### 3. Encrypt Your Wallet

- Always use a strong passphrase
- Use 20+ characters with mixed case, numbers, symbols
- Store passphrase separately from mnemonic

### 4. Offline Signing (Cold Storage)

1. Create transaction on online computer
2. Save unsigned transaction
3. Transfer to offline computer with this app
4. Sign transaction offline
5. Transfer signed transaction back
6. Broadcast from online computer

### 5. Regular Backups

- Backup wallet after every 100 transactions
- Store backups in multiple secure locations
- Test recovery process regularly

## 🐛 Troubleshooting

### Bitcoin Core Won't Start

1. Check if bitcoind is already running:
   ```bash
   ps aux | grep bitcoind
   ```

2. Verify Bitcoin Core installation:
   ```bash
   which bitcoind
   bitcoind --version
   ```

3. Check data directory permissions

### Slow Synchronization

- Initial sync takes days (350GB+ download)
- Ensure stable internet connection
- Consider using `--blocksonly` for faster sync

### Connection Issues

1. Check firewall settings
2. Ensure port 8333 is accessible
3. Verify router port forwarding (if needed)

### Wallet Not Loading

1. Check wallet file exists
2. Verify wallet encryption passphrase
3. Try loading with `bitcoin-cli`
